# RevPulse: Airbnb Revenue Optimization

**NC State University | Institute for Advanced Analytics**  
June 2026 – August 2026

## Live Dashboard

[Launch the RevPulse Interactive Dashboard](https://revpulse.streamlit.app/)

## Project Overview

RevPulse is a machine learning-driven revenue optimization tool
designed to help Airbnb hosts identify opportunities to improve
property performance and maximize annual rental revenue.

## Business Objectives

- Identify key factors influencing Airbnb rental revenue.
- Evaluate property performance across 10 cities.
- Provide personalized, actionable revenue optimization recommendations.

## Methodology

- Exploratory data analysis
- Data preprocessing and feature engineering
- Elastic Net regression
- Revenue scenario analysis
- Interactive dashboard development

## Key Results

- Analyzed Airbnb rental performance across 10 cities.
- Demonstrated up to a 248% increase in projected annual revenue
  under modeled optimization scenarios.
- Developed an interactive Streamlit dashboard to translate
  analytical findings into actionable recommendations.

## Limitations

Revenue improvements represent model-based projections rather
than guaranteed or observed increases in actual rental revenue.
